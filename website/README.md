# Falcon's site

Plain HTML and CSS, no build step and no scripts: open `index.html`, or put the folder on any static host (GitHub Pages can serve it from a workflow that uploads this folder).

- `index.html`, `style.css`: the page. The colours are the launcher's.
- `assets/`: the Falcon icon and two screenshots (the same ones as in `docs/screenshots`).

The benchmark numbers on the page are those of `docs/vs-vanilla.md` and `docs/benchmarks/vs-vanilla.json`; change them together, and say what was and was not measured.
